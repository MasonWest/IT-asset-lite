# IT 资产管理系统

办公室 IT 设备的台账工具。录入设备、扫码看详情、把显示器配到主机上、走状态流转、盘点、批量导入导出，
每一步都留操作记录。

一台设备一张二维码，贴在机器上，手机扫开就是它的详情页。显示器挂在哪台主机上，配对页一眼看清，
改也是一步。另有一张按真实平面图排的座位地图，谁坐哪、那一格有什么设备，当场就能盘。
键鼠、SSD、内存这类配件也能记，库存按流水现算。

整个系统在一台电脑上跑，数据只落一个 sqlite 文件：`backend/data/it_assets.db`。
换机器把这个文件拷过去就行，不用装数据库服务。

## 快速开始

需要 Windows 和 Python 3.10 以上。装依赖只需一次：

```bat
python -m pip install -r backend\requirements.txt
```

然后双击 `start.bat`。它会自己找 Python、挑一个没被占用的端口、构建前端、起服务，
五秒后打开浏览器。访问地址是 `http://127.0.0.1:8080`。

用的是机器上已经装好的 Python，不建虚拟环境。停止服务按 `Ctrl+C`，或者双击 `stop.bat`。

第一次启动要构建前端，所以那台机器得有 Node 18 以上。如果只是把系统搬到另一台电脑，
连 `frontend\dist` 目录一起拷过去，那台机器不装 Node 也能跑。

手动启动、指定端口、脚本细节见 [安装与启动](docs/user/install.md)。

## 第一次用

| 步骤 | 做什么 | 大约 |
| --- | --- | --- |
| 1 | 顶栏「空间地图」→「编辑点位」→「新增」→ 点画布空白处。成排的座位用「批量生成」 | 2 分钟 |
| 2 | 台账里新增或编辑设备，选上「所在点位」；也可以拿 Excel 模板批量导 | 5 分钟 |
| 3 | 台账页勾选设备 →「标签打印」，把二维码贴到机器上 | 3 分钟 |

新库第一次打开地图是空白画布，底图和点位都要自己画。系统不会预置一套别人的办公室。
完整走法，包括画房间、批量生成的参数、手机盘点，见
[安装与启动 · 第一次用](docs/user/install.md#第一次用10-分钟做出你的第一张图)。

## 常见问题

**接口报错，或者页面一片空白。** 多半是后端没起来，看一眼启动窗口，或者访问 `/api/health`，
正常会返回 `{"status":"ok"}`。

**提示「前端尚未构建」。** `frontend/dist` 不存在，跑一次 `start.bat --rebuild`。

**端口被占用。** 默认 8080，被占了会自动往后找十个。要固定的话：`set IT_ASSET_PORT=18080`。
别用 8000，本机的 C-Lodop 打印服务长期占着它。

**手机扫不出来二维码，或者扫开打不开。** 通常是二维码里的地址探到了用不了的网卡，比如 VPN 或虚拟机。
处理办法见 [扫不出来 / 打不开怎么办](docs/user/network.md#扫不出来--打不开怎么办)。

**删了数据库重启，怎么又冒出一堆设备。** 不会再这样了。启动只建表，外加六个设备类型，
不写任何资产。演示数据要自己跑 `python backend\seed.py`。
