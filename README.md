# IT 资产管理系统

办公室 IT 设备的台账工具。**录入 → 扫码查详情 → 主机显示器配对 → 状态流转 → 盘点 → 批量导入导出 → 操作审计**，双击一个脚本就能起服务。

- 每台设备一个二维码，贴到机器上，手机扫一下就能看到这台机器的全部信息
- 显示器到底挂在哪台主机上，一张页面看清、一步改完
- 一张按真实平面图画的空间地图：谁坐哪、那一格有什么设备、当场就能盘
- 键鼠 / SSD / 内存这类配件也能管（登记流水，库存现算，不猜）
- 手机浏览器打开就能用，不需要装 App

## 快速开始

**1. 装依赖（只需一次）**

```bat
python -m pip install -r backend\requirements.txt
```

**2. 双击 `start.bat`** —— 它会找 Python、挑端口、构建前端、起服务，5 秒后自动开浏览器。

**3. 浏览器打开 `http://127.0.0.1:8080`**，然后按下面的「第一次用」走三步。

> 用的是你电脑上已装好的 Python，**不建虚拟环境**。停止服务：窗口里 `Ctrl+C`，或双击 `stop.bat`。
> 手动启动、端口、脚本细节 → [安装与启动](docs/user/install.md)

## 第一次用：10 分钟做出你的第一张图

| 步骤 | 做什么 | 大约 |
| --- | --- | --- |
| 1 | 顶栏「空间地图」→「调整位置」→「新增」→ 点画布空白处。排一片就用「批量生成」 | 2 分钟 |
| 2 | 台账里新增/编辑设备，选「所在点位」；或者用 Excel 模板批量导 | 5 分钟 |
| 3 | 台账页勾选设备 →「标签打印」，二维码贴到机器上 | 3 分钟 |

地图第一次打开是**一张空白画布** —— 系统不替你猜办公室长什么样，这是故意的。

## 常见问题

**接口报错 / 页面空白？** 后端没起来 —— 看启动窗口，或访问 `/api/health`（正常返回 `{"status":"ok"}`）。

**提示「前端尚未构建」？** `frontend/dist` 不存在 —— `start.bat --rebuild`。

**端口被占用？** 默认 8080，`start.bat` 会自动往后找。手动指定：`set IT_ASSET_PORT=18080`。（**别用 8000**：本机 C-Lodop 打印服务长期占着。）

**手机扫码打不开？** 多半是二维码里的地址探到了用不了的网卡（VPN / 虚拟机）—— [处理办法](docs/user/network.md#扫不出来--打不开怎么办)。

**删了数据库重启，怎么又长出一堆设备？** 不会了：启动只建表 + 6 个设备类型，**不写任何资产**。演示数据得自己跑 `python backend\seed.py`。
