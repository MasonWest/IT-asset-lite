## 两条规矩

1. **`docs/archive/` 里的文件不修**。它们是证据 —— 包括里面的过时数字、旧链接、
   甚至已经脱敏前的措辞。要改就改 `docs/` 里的现行文档。
   因此 `tools/docs-check.py` 对 `docs/archive/` **跳过链接检查**（快照里的相对路径
   是按原位置写的，挪过来必然对不上）。
2. **归档 ≠ 删除**。项目里"当初为什么不这么做"只能在这些文件里找到答案。
