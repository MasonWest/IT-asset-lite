# 局域网与手机访问

服务默认监听 `0.0.0.0`，**同一局域网里的任何设备都能访问**，不需要额外配置。手机不用装 App，别的电脑也不用装。

## 第一步：拿到电脑的局域网地址

启动服务时控制台会打印一行：

```
手机扫码 : http://192.168.1.23:8080
```

## 第二步：在别的设备上打开它

- **手机**：连上同一个 Wi-Fi，浏览器地址栏输入这个地址。或者更省事 —— 打开某台设备的详情页，用手机相机 / 微信扫页面上的二维码，直接跳到那台设备的详情页。
- **另一台电脑**：浏览器输入同样的地址即可。

## 第三步（只在打不开时才需要）：放行防火墙

Windows 默认会拦掉外部访问 8080 端口。用**管理员身份**打开 PowerShell 或 CMD，执行一次：

```bat
netsh advfirewall firewall add rule name="IT资产管理8080" dir=in action=allow protocol=TCP localport=8080
```

（端口如果被自动顺延到了 8081，把上面命令里的 8080 换成实际端口。）

## 扫不出来 / 打不开怎么办

**先查防火墙**（见上面第三步）。**再查 IP 对不对** —— 电脑上有 VPN、虚拟机（VMware/VirtualBox）、WSL 时，程序自动探测到的网卡地址可能是用不了的那个。在 CMD 里执行 `ipconfig`，找到你正在用的那个网卡的 IPv4 地址（一般是 `192.168.x.x` 或 `10.x.x.x`）。

然后点右上角 **⚙ 设置**，把「自定义扫码地址」填成 `http://192.168.x.x:8080`，保存。二维码会立刻按新地址重新生成。

### 想改端口

三个办法任选一个：

```bat
set IT_ASSET_PORT=18080
start.bat                          :: 当前窗口临时生效
```

```bat
setx IT_ASSET_PORT 18080           :: 永久写进用户环境变量
```

或者直接 `python run.py --port 18080`。改了端口之后，二维码地址会自动跟着变，不用手动改设置。

### 其他可能

公司 Wi-Fi 开了「AP 隔离 / 客户端隔离」，同一 Wi-Fi 下设备也互相访问不了 —— 要么关掉隔离，要么用手机热点让电脑连上，再按热点网段填地址。

---

> 手机上如果打不开，多半是二维码里的地址不对（电脑装了 VPN / 虚拟机时会探测到用不了的网卡地址），
> 处理办法就是上面这一节。

装好之后怎么用：手机扫设备的二维码可以直接[标记盘点](../user/map.md#用手机盘点推荐这么用)。
