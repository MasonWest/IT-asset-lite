# 轻资产（配件）

键鼠套装、SSD、内存、转接头这类东西：不算固定资产、没有正式编码，
但确实在流转 —— 发给谁了、装在哪台机器上、拆下来放哪了，总得有人说得出。

「轻资产」就是管这个的。它和资产台账**平级**，两边的数字刻意分开算：
正式资产有多少台，永远不含键鼠套装。

## 先建一个「品类」

品类 = "一类东西"，比如「罗技 MK270 键鼠套装」「宏碁 N3500 固态 256GB」。
品类就是一张**字典表**：名称 + 品牌 / 规格（都选填）+ 单位。
它**不记数量、不记位置，也没有"追踪模式"要选** —— 建品类只回答"这是什么东西"，
至于有多少、在谁那儿，全部由下面的流水现算。

> 早先版本建品类时还要先选一套「追踪粒度」（按数量 / 按单件），这套**已经去掉了** ——
> 我们追的是"2 条内存装在 A100 上"，不需要给每条内存一个身份，SSD 也像键鼠一样按数量管。
> 所以现在建品类**没有任何要纠结的选项**。

## 然后登记「流转」

轻资产里**没有"直接改库存"这种操作**，一切都靠登记流水：
入库、分配（直接发给某人）、安装（装到某台正式资产上 / 放到某个点位）、
转移（换手）、拆卸（拆下来回库存）、归还、调整（盘点后的库存校正）、报损。

每次登记就是一条流水，**只加不改**。登记错了怎么办？点那条流水的「冲正」——
系统会**追加一条反向记录**（分配错了就记一条归还），原来的记录一个字不改，
两条互相指得出来。已确认的历史是证据，改它等于让时间线说谎。

几个你会遇到的规矩：

- **发出去的东西，得真有那么多**。这句适用于**每一条"从某处发出"的操作**：
  从库存发，查库存；从某人手上发（归还 / 转移 / 报损），查**他手上实际有多少**。
  说"从王五归还 3 套"而王五从没拿过，会被挡下并告诉你他手上是 0。
- **同一批东西不会同时在两个地方**：说"从 B 机拆 3 条"而它上面只装了 2 条，会被挡下，
  并告诉你它上面实际有几条。
- **换个人用，用「转移」一步到位**：`李四 → 周八`，不用先"归还"再"分配"。
  一次换手就是一条记录，时间线上看得出它是同一批东西换了人。
- **手抖连点不会重复入账**（每次提交带唯一标识，重复的直接挡掉）。
- **`/` 这种占位符不能当使用人** —— 它表示"没填"，不是一个人。
- **报损了就报损了**：已报损的件不能再走一次"入库"复活（那会把"已经报废"这件事抹掉）。
  如果是误报损、东西还在，用**「调整（盘盈）」**把它重新登记进库存 ——
  留下的是一条"调整"记录，而不是一条"入库"。
- **「冲正」按钮只在真能冲正时才出现**：报损、以及"从外部直接装到机器上"这类操作
  没有机械反向（系统不替你决定"撤销"该走哪条路），那一行的操作列会显示成 `—`，
  鼠标放上去会告诉你去用哪个操作。**不会给你一个点下去必然报错的按钮。**
- **「发生日期」只记到天**：填的是"这事哪天发生的"，不是"你什么时候点保存"。
  补录上周的账就填上周那天，账上就是上周，不会因为你今天操作就变成今天。
  时分不记（业务上不需要精确到几点几分）。
- **补录的流水会多一行「登记于 …」**：比如"发生 10/18 · 登记于 10/21 09:55"，
  一眼能看出这笔是事后补的；当天登记的不显示这一行。
- **「自 2026/10/20 起」说的是这段关系的开始**，不是最近一次领用：
  同一个人第二次领、同一台机器第二次加装，起始日期都还是第一次那天。
  什么时候会变？只有"全部还回去、库存清零"之后重新建立，才算新的一段关系、从新日期起。

## 配件关联了正式资产之后

装到某台主机上的 SSD，它的"当前使用人 / 所在点位"**每次现读**那台主机的信息 ——
主机换了人，配件的使用环境自动跟着变，不需要你改两遍。
但历史流水里存的是**当时的编码快照**：去年它装在哪，永远查得到，主机删了也查得到。

## 历史数据和期初库存

如果以前的分配记录在 Excel 里，可以「导入历史」：**历史导入只用于追溯，
不会自动变成"当前持有"** —— 系统不替你猜真实库存。

要把真实库存建起来，用「登记流转 → 期初确认」按实际盘点的结果登记，
这条必须填操作人（是谁确认的这份基线）。

台账上库存那一格显示「**未登记**」，就是在说：这个品类有流转记录、
却从没确认过基线 —— 去做一次期初确认。它显示「未登记」而不是 `0`，
是因为系统不替你猜真实库存。
