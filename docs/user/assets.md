# 资产台账

台账是系统的主界面：**一台设备一行/一卡**。下面按"你要做的事"排。

## 新增与编辑

- **新增**：「+ 新增资产」，填编号、类型、品牌型号、SN、状态、使用人、所在点位、购入日期、保修到期日、备注。
- **编辑**：点卡片/行进详情，改完保存。每次改动都会进这台设备的变更历史。
- **删除**：详情页里删。删掉的历史仍留在审计日志里。
- **字段可自定义范围**：设备类型自己加（服务器、交换机、平板…），并指定**类别**
  （`主机` / `显示` / `其他`）—— 类别决定它能不能参与主机↔显示器配对。
  每种类型在列表 / 详情 / 配对页都带自己的图标；自己新建的类型按名字里的关键字自动配图标。

## 找到你要的那台设备

- **筛选**：按类型 / 状态 / 使用人 / 位置，**这三类都可多选** —— 一次勾几个，筛选框里以标签显示已选项（超一个折叠成 `+N`）。
- **关键字搜索**：编号、SN、品牌型号、使用人都能搜。
- **顶部统计卡片**：点一下就是筛选。其中「**无点位资产**」= 还没在地图上标过位置的设备，点它就只看这些，方便去地图上补齐。
- **两种视图**：卡片 / 表格。
- **筛选条件和页码写在地址栏上**：刷新不丢、能加书签、也可以把链接原样发给同事；点进某台设备的详情再返回，筛选原样保留。
- **套装聚合**：打开后把「主机 + 它挂着的显示器」合并成一行看，列表立刻变短（实测 143 台 → 96 行）。表格视图里点行首的箭头能展开这套机子的显示器明细。**它只是换了个看法**：设备一台都没变，编号、状态、保修、使用人各自独立，配对关系也不动。**导出和打印标签永远按设备明细走**，不受这个开关影响。

## 点位：这台机器在哪

列表的每张卡片和表格里都有一列「**点位**」：挂在点位上的显示蓝标签 `点位:W24`，没挂的显示灰底「未设点位」。扫一眼就知道这台机器在哪、还有哪些没标位置（这比看序列号直观得多 —— 序列号一般是空的）。

点进任何一台设备，「归属与维保」里的第一项就是「**所在点位**」：显示点位编码和**这一格的使用人**（点位归谁用的是与地图同一份数据）。**点编码直接跳到空间地图并选中那一格**。没挂点位的显示「未挂点位」，并说明去哪儿挂。

挂/摘点位的具体操作见 [空间地图 · 挂设备到点位](map.md#挂设备到点位两种入口看手头有什么)。

## 主机 ↔ 显示器配对

一台主机可挂多台显示器；一台显示器同一时刻只能挂在一台主机上。

- 支持绑定 / 换绑 / 解绑，**解绑不删记录**（改成失效并记下解绑人和时间）。
- 给主机加显示器时**默认只列还没配出去的**（要看已挂机的点一下开关）；主机列表可「只看没配显示器的」。
- 点「+ 加显示器」说没有可选的 → 多半是类型类别不对，见 [常见问题](faq.md#常见问题)。

## 状态流转

在库 / 在用 / 维修中 / 已报废；操作有 领用 / 归还 / 送修 / 维修完成 / 报废 / 恢复入库。

非法流转由服务端拦下（409）并给出人话原因 —— 比如已报废的设备必须先「恢复入库」才能领用。每次流转都要求填操作人（系统没有账号体系，见 [已知限制](faq.md#已知限制这些是故意的不是没做完)）。

## 变更历史时间线

录入 / 信息变更 / 状态流转 / 配对解绑 / 盘点标记，每台设备一条倒序时间线。
它和「操作审计」的区别：这里是**设备视角**（这台机器身上发生过什么），审计是**操作者视角**（谁在什么时候做了什么）。

## 二维码与标签打印

- **每台设备一张二维码**，内容就是它自己的详情页地址；可下载 PNG。
- **批量打印**：台账页勾选设备 → 「标签打印」→ 直接调浏览器打印（A4 排版）。左边可按**设备类型 + 存放位置**缩范围（补打某一台时不用在全部设备里翻），再调大小 / 每行个数 / 显示字段。
- 手机扫二维码 = 打开那台设备的详情页，顶部会直接出现「标记已盘 / 异常」按钮（见 [盘点](inventory.md)）。

## 批量导入

支持 `.xlsx` / `.csv`。流程：下载模板 → 拖入文件 → **预览**（新增 / 更新 / 无变化 / 失败四桶 + 逐行问题）→ 确认入库。可选「仅新增」或「新增或更新」。

三条最常见的规矩（都在 [常见问题](faq.md#常见问题) 里有详述）：

- **空单元格 = 保持原值不变**，不是清空；要清空得显式写 `-`。
- **有错的行跳过，其余照常入库**，不会整份白干。
- **导出的列和导入模板是同一份定义**，所以原样导回去会显示「无变化」—— 这正是列对齐的证明。

## 批量导出

当前筛选或全部；可选附带配对的显示器信息。列与导入模板完全一致，改一改能直接导回来。

## 操作审计

每一次写操作留一条：时间、操作人、IP、操作类型、操作对象、变更内容、结果。**失败的尝试也记**。可按条件筛选、可导出；**只读，不提供编辑删除**。
